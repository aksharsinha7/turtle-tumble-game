# Turtle Tumble

Turtle Tumble is a 2D pixel-art platformer game built with Unity where the player controls a turtle through side-scrolling platforming challenges.

## Features

- 2D pixel-art gameplay
- Platforming mechanics
- Unity physics system
- Side-scrolling level design

## Built With

- Unity
- C#
- Pixel-art assets

## How to Play

1. Download the project files
2. Run `NSLCollab.exe`

## Gameplay

The player navigates platforming environments while avoiding hazards and obstacles.
